# Dàn ý báo cáo

1. Trang bìa: tên đề tài, lớp, giảng viên, thành viên.
2. Mục tiêu và yêu cầu: REST API, phân tầng, DI, kiểm thử.
3. Công nghệ sử dụng: Flutter/Dart, http, GetIt, BLoC, Mocktail.
4. Clean Architecture: sơ đồ Presentation → Domain abstraction ← Data implementation.
5. Dependency Inversion & Repository Pattern.
6. UseCase GetPosts và luồng gọi API.
7. Dependency Injection: WidgetsFlutterBinding, configureDependencies, BlocProvider.
8. Giao diện demo: loading, danh sách bài viết, lỗi và retry.
9. Unit Test: mock repository, test kết quả và test lỗi.
10. Kết luận, hạn chế, hướng phát triển.
